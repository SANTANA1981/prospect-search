# prospect-search
Web application for B2B prospecting with advanced filters

## Backend fiscal agent

Endpoints:
- `POST /api/agent/chat`
- `POST /api/agent/analyze`
- `GET /api/agent/history`

Environment variables:
- `OPENAI_API_KEY`
- `OPENAI_MODEL`
- `BRASILAPI_BASE_URL`
- `FISCAL_STATUS_API_URL`
- `FISCAL_CERTIDAO_API_URL`
